# 用户增长 · 增长循环与用户分层

## 一、增长循环（Growth Loops）

> 漏斗已过时，2025+ 主流是"循环"——用户的行为如何带来更多用户。

### 三类产品的专属增长循环

**SaaS 增长循环**：
```
新企业付费 → 部署后 Admin 邀请同事 → 同事激活 → 部门扩张 → 
带动其他部门 → NRR 提升 → 公司预算扩张 → 复购扩张
```

**AI 增长循环（内容增长循环）**：
```
用户产生有用输出 → 复制分享出去 → 接收者看到水印/署名 → 
点击试用 → 注册 → 产生有用输出 → ...
```

**平台增长循环（双边）**：
```
商家上架优质库存 → 买家搜到优质结果 → 留线索/询价 → 
快速被响应/成交 → 买家口碑传播 → 更多买家 → 商家收益 → 
更多商家入驻 → 更优质库存
```

### 中台报表围绕循环

不是漏斗，而是"每个循环节点的转化率与时长"。

## 二、用户分层

### RFM 升级版（Recency, Frequency, Monetary + Value）

```
                        高
   ┌──────────────────────────┐
   │ V1 高价值忠诚      V2 高价值新晋│
   │ (维护 + 推荐)      (深化 + 培养)│
   │                              │
   │ V3 高价值流失      V4 普通活跃 │
   │ (召回 + 挽留)      (提升 + 转化)│
   │                              │
   │ V5 普通流失        V6 沉默低值 │
   │ (筛选 + 召回)      (轻成本试)  │
   └──────────────────────────┘
                        低
        近期活跃 高           近期活跃 低
```

### LCM 阶段（生命周期）

- 引入期 / 成长期 / 成熟期 / 沉默期 / 流失期 / 召回期
