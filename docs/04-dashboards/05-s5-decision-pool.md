# S-5 决策待办池 · UI Spec

> **回答**：今天我必须处理的事情是什么？  
> **定位**：总产品经理"每天的入口页"  
> **触发**：每天 08:00 自动推送企微 + 站内

## 布局

```
Row 1 (问候 + 统计)                高 80px
Row 2 (紧急重要区)                 高 自适应
  · ≤ 3 张大卡，每张占满宽度，高 240px
Row 3 (重要不紧急区)               高 自适应
  · 列表形式，每行 64px
Row 4 (本周已决策列表)             高 自适应
Row 5 (助理快速输入框)             固定底部 高 80px
```

## 紧急决策卡（`<UrgentDecisionCard>`）

```
┌──────────────────────────────────────────────────────────────┐
│ 🔴 紧急 + 重要（≤24h 必须处理）  3 件                        │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ ① AI-写作 DAU 异常下降 23%                                │ │
│ │   📊 数据：异动检测 9:13 触发                              │ │
│ │   🧠 归因：新版本响应延迟 P99 从 800ms → 2.8s              │ │
│ │   💡 建议：A) 立即回滚 B) 灰度暂停 C) 监控观察 24h         │ │
│ │   [选 A]  [选 B]  [选 C]  [💬 详谈] [转交张三]            │ │
│ └──────────────────────────────────────────────────────────┘ │
```

### 卡片规约

- 左侧红色 4px 边带（P0）/ 黄色（P1）
- 主按钮 [选 A] 大号 primary
- 次按钮：详谈 / 转交 / 拒绝
- 选择后自动登记决策追溯库 + 派发任务

## 助理输入框（底部固定）

```
┌────────────────────────────────────────────────────┐
│ 💬 想问什么？ [输入框 + 快捷命令 @/#// + 截图]  发送 │
└────────────────────────────────────────────────────┘
```

快捷命令：
- `@用户`：召唤角色
- `#分群`：插入分群
- `/决策`：快速登记决策

## 关键规则

- **AI 浓缩**：从全公司所有异动/风险/评审中浓缩出"今日必须决策的 ≤7 件事"
- **决策即留痕**：点选 [A/B/C] 后自动登记决策追溯库 + 触发后续动作
- **永远不超过 10 件**：超过时强制 AI 重新优先级排序或合并
- **晨报推送**：每天 8:00 自动推送企微/邮件

## 数据接口

```
GET /api/dashboard/s5/decisions
  Query: user_id (default: current)
  Response: {
    urgent: [...max3 items],
    important: [...items],
    thisWeekDecided: [...items],
    stats: { pending, decidedThisWeek }
  }

POST /api/dashboard/s5/decide
  Body: { itemId, choice, comment }
  Effect: 自动创建决策追溯记录 + 触发后续动作

POST /api/dashboard/s5/transfer
  Body: { itemId, transferTo, comment }
```
