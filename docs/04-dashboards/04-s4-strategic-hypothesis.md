# S-4 战略假设追踪 · UI Spec

> **回答**：年初定的战略假设现在验证到什么程度？要不要调整？  
> **概念**：每个战略假设作为"长期实验"持续追踪验证度。

## 布局

```
Row 1 (年度进度条 + 状态统计)         高 80px
Row 2 (假设卡片墙 - 瀑布流)          高 自适应
  · 每张卡 480px 宽，高自适应
  · 桌面端 3 列，平板 2 列
```

## 顶部统计

- 总数 + ✅已验证 + 🟢顺利 + 🟡偏离 + 🔴失败 + ⚪进行中
- 进度可视化堆叠条
- [+ 新增假设] 按钮（仅高管权限）

## 假设录入表单

| 字段 | 类型 | 必填 |
|---|---|---|
| 假设描述 | 文本 | ✓ |
| 假设类型 | 选 | ✓ |
| 北极星指标 | 选指标 | ✓ |
| 先导指标 | 多选 | ✓ |
| 假设前提 | 文本 | ✓ |
| 验证方法 | 选 | ✓ |
| 责任人 / 起止 | — | ✓ |
| 失败后果 | 文本 | ✓ |

## 数据接口

```
GET /api/dashboard/s4/hypotheses
  Query: year, status
  Response: {
    summary: { total, succeeded, ontrack, deviated, failed },
    items: [{ id, title, owner, deadline, progress, leadingIndicators, aiDiagnosis, suggestions }]
  }

POST /api/dashboard/s4/hypotheses  (新增)
PUT  /api/dashboard/s4/hypotheses/{id}  (更新)
```

## 联动

- 每个战略决策必须关联到假设
- 假设状态变化自动通知关联人
- 季度评审会自动调取假设进展
