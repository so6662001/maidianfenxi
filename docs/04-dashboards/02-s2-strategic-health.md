# S-2 战略健康度雷达 · UI Spec

> **回答**：公司整体业务变好还是变差？哪里红灯？  
> **用户**：总产品经理 + CEO + 各产品线负责人  
> **频率**：T+1 + 实时关键指标

## 布局（24 栅格）

```
Row 1 (顶部 KPI 条 10 个数字)       高 96px
Row 2 (主体三栏)                    高 420px
  ├ 5 维健康雷达           8 列
  ├ 三产品健康对比（条形）  8 列
  └ 4 周演进（折线）       8 列
Row 3 (异动 TOP10 表格)             高 360px
Row 4 (本周战略关注 3 件事)         高 200px
```

## 模块

### KPI 条（横向 10 个）

```
总活跃企业 / 总DAU / NRR / 周净增 / 周流失 / 周收入 / 撮合GMV / NPS / 健康分 / 异动数
```

使用 `<KpiCard>` mini 版（高 80px），可横向滚动。

### 5 维健康雷达

- 组件：ECharts radar
- 5 维：增长 / 留存 / 收入 / 质量 / 效率
- 多 series：SaaS / AI / 平台 三产品同图对比
- hover 显示具体子项

### 三产品健康对比

- 组件：ECharts bar (horizontal)
- 每个产品一条，颜色按健康分（红/黄/绿）
- 显示数值 + 趋势箭头

### 4 周演进

- 组件：ECharts line（多 series）
- X 轴：周次
- Y 轴：健康分
- 标注重大事件（版本发布、活动）

### 异动 TOP10 表格

| 列 | 字段 | 排序 |
|---|---|---|
| 等级 | P0/P1/P2 Badge | ✓ |
| 指标 | 指标名 | ✓ |
| 变化 | ±% + 趋势 | ✓ |
| 责任人 | 头像 + 名字 | — |
| 可能原因 | LLM 归因摘要 | — |
| 建议 | 关键词 | — |
| 动作 | [处理] [圈人] [提单] | — |

行间内嵌 `<AnomalyCard>` 详情可展开。

### 战略关注 3 件事

- 使用 `<DecisionCard>` ×3
- AI 浓缩本周最重要 3 件待决策事项
- [一键加入决策池] 全部入 S-5

## 健康分计算口径

| 维度 | 权重 | 子项 |
|---|---|---|
| 增长 | 25% | 周新增/流失 + 收入环比 |
| 留存 | 25% | 7日/30日留存加权 |
| 收入 | 20% | ARPU 趋势 + NRR |
| 质量 | 20% | 报错率 + 零结果率 + NPS |
| 效率 | 10% | 需求达成率 + 迭代周期 |

不同产品权重可配置。

```
    radar: { products: [...], dimensions: [...] },
    bars: [...],

    anomalies: [...top10],
    weeklyFocus: [...3 items]
  }
```
