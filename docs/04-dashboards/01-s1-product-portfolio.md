# S-1 产品组合矩阵 · 高保真原型规约

> **回答的决策问题**：下季度研发预算/人力应该投给谁？砍谁？  
> **目标用户**：总产品经理、CEO、CFO  
> **数据频率**：T+1（每日 06:00 刷新）

### 模块 C · KPI 摘要条

```
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│ 产品总数         │ 总营收           │ 加权 ROI         │ 健康产品比例     │
│ 12              │ ¥4.2 亿          │ 8.3x             │ 67%              │
│ 新增 +2 退 -1   │ ↑12% (vs 上季)   │ ↑0.5x            │ ↓5pp ⚠           │
└─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

| 卡 | 主指标 | 计算口径 | 副信息 | 颜色规则 |
|---|---|---|---|---|
| 1 | 产品总数 | `count(active)` | 本季新增/退场 | 中性灰 |
| 2 | 总营收 | `sum(产品.季度营收)` | 环比/同比 | 涨绿/跌红/平灰 |
| 3 | 加权 ROI | `sum(营收) / sum(成本)` | 环比 | 同上 |
| 4 | 健康产品比例 | `count(健康分≥70) / count(全部)` | 环比 | 同上 |

### 模块 D · 矩阵图（核心）

#### 字段定义

| 维度 | 字段 | 类型 | 计算 | 阈值 |
|---|---|---|---|---|
| X 轴 | 相对优势 | [0,1] | `0.4×市占率 + 0.3×NPS + 0.3×留存` | 0.5 为分隔 |
| Y 轴 | 增速 | % | `(本季-上季)/上季` | 30% 为分隔 |
| 气泡大小 | 营收 | 货币 | `sum(产品.季度营收)` | 对数刻度，20-80px |
| 气泡颜色 | 健康分 | [0,100] | 五维加权 | 红<60≤黄<80≤绿 |
| 气泡标签 | 产品名 | 文本 | — | 字号 12px，气泡>30px 显示 |
| 气泡边框 | 战略标记 | 枚举 | 重点/关注/默认 | 由战略假设关联 |

#### 象限定义

| 象限 | 条件 | 背景色 | 默认建议 |
|---|---|---|---|
| ⭐ 明星 | 增速≥30% ∧ 优势≥0.5 | #E8F8F0 | 加大投入 |
| ❓ 问题 | 增速≥30% ∧ 优势<0.5 | #FFF8E1 | 设里程碑观察 |
| 💰 现金牛 | 增速<30% ∧ 优势≥0.5 | #E3F2FD | 维持挤奶 |
| 💀 瘦狗 | 增速<30% ∧ 优势<0.5 | #FFEBEE | 砍或转型 |

#### 交互行为

| 交互 | 触发 | 行为 |
|---|---|---|
| Hover 气泡 | 鼠标移入 | Tooltip：产品名/营收/增速/ROI/健康分/责任PM/象限 |
| Click 气泡 | 鼠标点击 | 跳转该产品业务模型看板（新标签页） |
| 右键 气泡 | 右键 | 菜单：查看明细/加入观察/发起评审/圈定决策 |
| 双击 气泡 | 双击 | 进入产品 360° 详情 |
| Hover 象限 | 移入象限 | 象限淡黄高亮，右侧 ROI 表自动筛选该象限 |
| Hover 气泡 | 移入时 | 显示过去 4 季度轨迹拖尾 |
| 拖拽边界 | 拖象限线 | 临时调整阈值，可保存为个人偏好 |

#### 数据稀疏处理

| 情况 | 处理 |
|---|---|
| 产品 < 3 个 | 不显示矩阵，改用列表 + 文案 |
| 上季数据缺失 | 气泡显示在中心 + Tooltip 标注 |
| 营收 = 0 | 最小尺寸 + 灰色边框 + 提示 |
| 新上线产品 | 空心气泡 + "NEW" 标签，不参与排序 |

### 模块 F · AI 决策建议卡

```
┌────────────────────────────────────────────────────────────────┐
│ 💡 建议 #1                                            置信度 ⭐⭐⭐ │
│ ──────────────────────────────────────────────────────────── │
│ 📌 建议：下季度从 SaaS-旧版OA 抽调 30 人月给 AI-写作助手        │
│                                                                  │
│ 🧠 依据：                                                       │
│   · SaaS-旧版OA 落入"瘦狗"象限（增速 -15%，优势 0.32）          │
│   · AI-写作助手在"问题"象限，增速 +80%，缺人导致迭代慢         │
│   · 历史相似决策 (3 次)：平均 ROI 提升 2.3x                     │
│                                                                  │
│ 📊 预期效果：                                                   │
│   · AI-写作助手季度营收 +40%                                     │
│   · SaaS-旧版OA 维护成本 -25%                                    │
│                                                                  │
│ ⚠️ 风险：                                                       │
│   · 旧版 OA 客户流失加速（预估 -8%）                            │
│   · 团队转岗适应期 6-8 周                                       │
│                                                                  │
│ [📋 发起评审] [💬 详细分析] [📌 记录决策] [👎 不采纳]           │
└────────────────────────────────────────────────────────────────┘
```

| 字段 | 类型 | 生成方式 |
|---|---|---|
| 建议标题 | 短文 ≤ 30 字 | LLM 基于规则模板 |
| 依据 | 列表 3-5 项 | 规则引擎 + 相似案例检索 + LLM |
| 预期效果 | 列表（量化） | 历史相似决策回归预测 |
| 风险 | 列表（必填） | 规则库 + LLM 反向思考 |
| 置信度 | 星级 [1-5] | 历史相似数 × 准确率 × 数据完整度 |

| 按钮 | 行为 | 后续 |
|---|---|---|
| 📋 发起评审 | 创建评审会议 + 议题摘要邮件 | 议题进入评审，结果回填 |
| 💬 详细分析 | 唤起决策助理，自动带入建议 | 助理解释、扩展、模拟 |
| 📌 记录决策 | 唤起决策追溯库表单 | 决策状态 → 已采纳 |
| 👎 不采纳 | 反馈框 + 关闭 | 反馈进入学习层 |

## 三、状态规范

| 状态 | 触发 | 表现 |
|---|---|---|
| 首次进入无数据 | 公司刚接入 | 引导图 + "请先配置产品数据" + [前往配置] |
| 当前筛选无数据 | 筛选过严 | "当前筛选无产品" + [清空筛选] |
| 数据过期 | T+1 > 36h | 顶部黄色 Banner："数据已过期 [刷新]" |
| 加载中 | 数据请求中 | 骨架屏（不转圈），3s 后提示"加载较慢" |
| 加载失败 | 接口报错 | 错误图 + [重试] + 错误码（DEV） |
| 无权限 | 权限不足 | "暂无权限" + [申请权限] + 联系人 |
| 部分数据缺失 | 某产品不全 | 行/气泡显示"—" + hover 提示缺失字段 |

## 四、响应式

| 宽度 | 调整 |
|---|---|
| ≥ 1920 | 全屏标准 |
| 1440-1920 | 矩阵 65% / 排行 35%，AI 建议 3 张横排 |
| 1280-1440 | 矩阵 70% / 排行下方堆叠 |
| 1024-1280 | 单列堆叠 |
| < 1024 | "请使用 PC 端访问" |

## 五、权限矩阵

| 角色 | 可见数据 | 可操作 |
|---|---|---|
| 总产品经理 / CEO / CFO | 全部产品 | 全部 + 锁定矩阵口径 |
| 产品线负责人 | 本线 + 跨线只读 | 评审/记录决策/订阅 |
| PM | 本人负责产品 + 公司聚合 | 记录决策/订阅 |
| 数据 PM | 全部只读 + 口径编辑 | 编辑指标口径 |
| 其他角色 | 公司聚合（无单产品营收） | 仅订阅 |
