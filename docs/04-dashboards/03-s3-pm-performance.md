# S-3 PM / 团队效能榜 · UI Spec

> **回答**：哪些 PM 判断力强？哪些团队需要辅导/调整？  
> **用户**：总产品经理、CEO（HR 协同）  
> **数据来源**：决策追溯库 + 项目管理系统

## 布局

```
Row 1 (公司级总览 6 KPI)            高 96px
Row 2 (主体)                        高 600px
  ├ PM 个人榜 Table         16 列
  └ 团队/产品线对比（条形） 8 列
Row 3 (能力雷达 + AI 洞察)          高 240px
```

## KPI 条

- 需求总数 / 上线 / 达预期 / 平均迭代 / 预测偏差 / 复盘完成率

## PM 个人榜

| 列 | 说明 |
|---|---|
| 排名 | 默认按决策准确度排序 |
| PM | 头像 + 名字 |
| 需求数 | 季度需求数 |
| 上线数 | 已上线数 |
| 达预期率 | % + 进度条颜色 |
| ROI | 上线后指标提升 / 投入 |
| 预测准确度 | 1 - |预期-实际| / 预期 |
| 迭代天数 | 中位数 |
| 技能雷达 | 点击展开 mini radar |

## 团队对比（条形）

- X：ROI / 达预期率 / 预测准确度
- Y：团队/产品线

## 能力雷达详情（展开）

5 维：用户洞察 / 数据驱动 / 决策准确 / 执行力 / 协同力 / 创新性

## AI 组织洞察

- 自动识别"持续下滑"、"显著高于"、"建议内训"等
- 每条带数据依据

## 计算口径

| 指标 | 公式 |
|---|---|
| 需求达预期率 | `count(达成 or 部分达成) / count(已上线)` |
| ROI | `(上线后 90 天指标提升带来价值) / 研发投入` |
| 预测准确度 | `1 - |预期 KPI - 实际 KPI| / 预期 KPI` |
| 迭代天数 | `需求录入 → 上线日的工作日中位数` |
| 能力雷达 | 多维评估 + 360 同事评分（可选） |

## 隐私与公平

- 仅总 PM/CEO 可看全表
- 产品线负责人仅看本线
- PM 本人只看自己详情
- 数据用于辅导、不作为唯一绩效依据
- 评估周期建议 ≥ 1 季度（避免短期波动）
- 提供"申诉"通道
