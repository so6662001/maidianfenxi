# G-1 用户增长决策中枢 · UI Spec

> **服务对象**：增长负责人、运营负责人、产品 PM  
> **频率**：T+1 + 实验实时

## 布局

```
Row 1 (头部 + 筛选)                              高 112px
Row 2 (增长循环健康度 - 按产品)                  高 240px
Row 3 (用户分层迁移 - 桑基)                      高 320px
Row 4 (增长瓶颈识别 - AI 自动)                   高 240px
Row 5 (增长机会卡片 - 可一键发起实验)           高 自适应
Row 6 (在跑实验 + 增长动作库)                    高 360px
Row 7 (用户全景画像入口)                         高 120px
```

## 模块

### 增长循环健康度（按产品）

```
SaaS  邀请循环转化率 28% (↑3%) │ 复购循环 12% (↓2%⚠)
AI    分享循环 5% (↑1%) │ 内容沉淀循环 18% (↑5%)
平台  双边循环 (商家→买家) 1:3.2 │ (买家→商家) 1:0.8
```

每产品多个循环，颜色按健康度。

### 用户分层迁移（桑基）

- RFM × LCM 12 类用户
- 节点：用户分层
- 流向：周/月间迁移
- 红色流向：流失方向

### 增长瓶颈识别

- AI 自动产出 TOP 3 瓶颈
- 每条带：现状指标 / 行业基准 / 提升空间 / 推荐动作

```
🔴 #1 SaaS 试用→付费转化率 12%，行业基准 25%（潜力 +1300 客户/月）
   建议：A) 优化 onboarding  B) 加首次成功钩子  C) 销售介入
```

### 在跑实验

- 实验列表
- 每条显示：名称 / 已跑天数 / 当前提升 / 显著性

- 点击启动
