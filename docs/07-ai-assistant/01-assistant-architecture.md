# AI 决策助理 · 产品架构

> 中台对外的**唯一统一入口**。

## 一、6 级能力模型

| 级别 | 能力 | 示例 | 阶段 |
|---|---|---|---|
| L1 | 数据查询 | "上周 SaaS DAU" | MVP |
| L2 | 趋势对比 | "和上月比变化" | MVP |
| L3 | 归因分析 | "为什么下降" | MVP |
| L4 | 行动建议 | "给我 3 条挽留策略" | V1 |
| L5 | 决策辅助 | "我应该砍掉这个功能吗" | V2 |
| L6 | 主动洞察 | "今天有 3 件事需要您关注" | V3 |

## 二、产品形态

| 形态 | 用法 |
|---|---|
| **桌面端独立 App** | 工作台首页，左侧对话 + 右侧渲染图表/卡片/操作按钮 |
| **嵌入业务系统** | 所有业务系统右下角 `<AssistantBubble>` 浮窗 |
| **企微/钉钉 Bot** | 移动场景，发文字/语音/图片 |

| **API** | 暴露给业务系统调用（与 OpenAPI 联动） |

## 五、对话规范

### 永远输出"数据 + 解释 + 行动"三件套

- 数据：具体数字 + 时间范围 + 维度
- 解释：自然语言归因
- 行动：可点击操作按钮（≥ 1 个）

### 数据来源可追溯

- 每个数字旁有 "📎" 图标
- 点击展开：SQL + 时间戳 + 数据集

### 操作必须二次确认

- 涉及 > 100 人触达 / 资金 / 重大决策 → 必须人工 confirm

### 权限隔离

- 助理基于当前用户身份返回数据，不可越权
- 越权数据 → "您暂无该数据权限"

### 多轮上下文

- 保持当前会话的"产品 / 时间 / 分群"上下文
- 上下文最长保留 20 轮

### 可解释性

- 所有 AI 建议必须说出"为什么这么建议"
- 显示置信度（高/中/低）

## 六、安全与合规

| 风险 | 缓解 |
|---|---|
| 越权数据访问 | 行级 + 字段级权限校验 |
| 敏感数据泄露 | 字段脱敏 + 输出过滤 |
| Prompt 注入 | 系统提示词隔离 + 输入校验 |
| 误操作 | 所有写操作二次确认 |
| 误导决策 | AI 建议必须显示置信度 + 不替代人决策 |
| 审计 | 所有对话 + 工具调用全留痕 |
| LLM 幻觉 | RAG + 数据强制带 SQL 来源 |
| 内容合规 | 输出过滤敏感词 + 法务审核 |

## 七、模型路由

| 场景 | 模型 | 理由 |
|---|---|---|
| 简单查询（L1-L2） | 小模型（Qwen-Turbo / GPT-4o-mini） | 低成本 |
| 归因分析（L3） | 中型模型 | 平衡 |
| 决策辅助（L5） | 大模型（GPT-4 / Claude Sonnet） | 准确 |
| 主动洞察（L6） | 大模型 | 准确 |
| 工具调用 Plan | 中型模型 | Function Calling 能力 |

## 八、技术实现选型

- LLM 框架：LangChain4j
- 主 LLM：OpenAI GPT-4 / Anthropic Claude
- 备选 LLM：通义千问 / 文心一言（国内合规）
- Embedding：text-embedding-3-small / bge-m3
- 向量库：Milvus / Qdrant
- 后端：Spring Boot + LangChain4j
- 前端：Vue3 + Markdown 渲染 + 流式 SSE
