## 助理通用规范

| 项 | 规范 |
|---|---|
| 响应时间 | 简单 < 2s，复杂 < 8s |
| 必带元素 | 数据 + 解释 + 行动建议 |
| 数据来源 | 每数字带 📎 可点开看 SQL |
| 多轮上下文 | 保持产品/时间/分群上下文 |
| 拒绝场景 | 越权 → "您暂无权限"；无法回答 → "已记录给数据 PM" |
| 错误处理 | 数据失败 → 给原因 + 替代查询建议 |
| 反馈 | 每条回答下 [👍][👎]，👎 弹反馈框 |
| 安全 | 永远不替代人决策，置信度透明 |
