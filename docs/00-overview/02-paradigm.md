# 决策操作系统范式

## 一、范式核心：从「看数据」到「做决策」

### 旧范式（传统 BI）
```
数据采集 → 数仓 → 报表配置 → 用户主动来看 → 看完散场
```

**问题**：报表越做越多、信息过载、看完不知道做什么、决策不留痕。

### 新范式（决策操作系统）
```
数据采集 → 异常发现 → 智能归因 → 决策建议 → 一键行动 → 结果追溯 → 知识沉淀
```

**优势**：主动 Push、闭环可追溯、组织能力可累积。

## 二、五层架构

```
┌────────────────────────────────────────────────────────────┐
│ L1 决策驾驶舱（5 张战略看板，给高管）                          │
├────────────────────────────────────────────────────────────┤
│ L2 智能洞察引擎（不是报表，是 Push）                            │
│    异动检测 + 自动归因 + 决策建议 + 一键行动                    │
├────────────────────────────────────────────────────────────┤
│ L3 业务模型看板（3 套，对应 SaaS/AI/平台）                      │
│    每类产品用自己的业务模型，不强行同构                          │
├────────────────────────────────────────────────────────────┤
│ L4 中台能力组件（输出给业务系统嵌入）                            │
│    用户画像组件、功能健康度组件、查询参数分析组件等               │
├────────────────────────────────────────────────────────────┤
│ L5 决策追溯库（每次重大决策的输入/输出/复盘）                    │
└────────────────────────────────────────────────────────────┘
```

## 三、4 大核心子系统

### A. 对话式决策助理（Conversational Decision Assistant）

中台**唯一统一入口**。能力等级：

| 级别 | 能力 | 示例 |
|---|---|---|
| L1 | 数据查询 | "上周 SaaS DAU" |
| L2 | 趋势对比 | "和上月比变化" |
| L3 | 归因分析 | "为什么下降" |
| L4 | 行动建议 | "给我 3 条挽留策略" |
| L5 | 决策辅助 | "我应该砍掉这个功能吗" |
| L6 | 主动洞察 | "今天有 3 件事需要您关注" |

### B. 嵌入式能力组件（Embeddable Capability Components）

把分析能力封装成 Vue3 组件 / 微前端，嵌入业务系统：

- `<UserProfile360 />` 用户 360° 画像
- `<FeatureHealth />` 功能健康度
- `<SegmentBuilder />` 自助分群
- `<ChurnRiskCard />` 流失风险
- `<JourneyDesigner />` 旅程编排
- ……（详见 11-embedded-components）

### C. 智能洞察引擎（Intelligent Insight Engine）

四层 + 一层反馈：

```
L0 数据层（指标平台 + 行为明细 + 业务上下文）
L1 分析层（异动检测 + 维度归因 + 因果分析）
L2 智能层（LLM 摘要 + 决策建议生成）
L3 行动层（推送 + 决策待办池 + 一键行动按钮）
L4 学习层（反馈收集 → 调阈值 / 调推荐 / 调归因权重）
```

### D. 决策追溯库（Decision Traceability Library）

每个决策结构化登记：
- 5 种模板（产品/资源/战略/组织/应急）
- 自动数据快照
- 30/60/90/180 天自动复盘
- 知识沉淀 → 反哺 AI 建议

## 四、用户增长贯穿主线

中台所有能力都服务于一个最终目标：**用户增长**。

```
用户分析 → 用户分群 → 增长 Playbook → 触达 / Journey → 实验 → 决策追溯
```

37 个用户增长 Playbook 是中台的"实战武器库"。

## 五、关键设计原则

1. **决策驱动而非数据驱动**：从业务决策反推需要什么数据
2. **三类产品差异化建模**：SaaS / AI / 平台 各有自己的业务模型
3. **AI 给建议、人做决策**：永远不让 AI 替代人拍板
4. **嵌入而非替代**：嵌入到业务工作流，不要求业务方"过来用"
5. **决策必留痕**：所有重大决策强制登记，沉淀组织记忆
6. **指标平台一元化**：所有指标只在一处定义，避免口径漂移
7. **可观测性**：每个 Playbook、每个建议、每个决策都可量化评估
