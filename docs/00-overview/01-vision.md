# 中台愿景与定位

## 公司背景

我们是一家拥有多个产品线的集团公司，目前包括：

- **SaaS 产品线**：订阅制企业级软件（如发票、合同、CRM 等模块）
- **AI 产品线**：基于 LLM 的智能助手产品
- **平台产品线**：双边市场平台（商家发布库存、买家在线询价/留线索，平台收取会员费与流量费）

## 中台核心使命

> 建立一个面向公司**总产品经理 + 各产品 PM + 运营 + CSM + 销售**的「**决策操作系统**」，让公司基于真实用户数据做出更准、更快、可复盘的产品与运营决策。

## 三大核心价值

### 1. 决策智能化
不只是"看数据"，而是「**异动发现 → AI 归因 → 决策建议 → 一键行动 → 结果追溯**」全链路闭环。

### 2. 能力被嵌入
中台不只是"等业务方来用"，而是把能力（用户画像、流失预警、分析组件）**嵌入到各业务系统的工作流**中，让数据消费零摩擦。

### 3. 组织记忆沉淀
通过**决策追溯库**沉淀每个决策的"输入-输出-复盘"，形成组织级的"决策方法论"，是 3-5 年后比数据本身更值钱的资产。

## 与传统 BI / 数据中台的本质区别

| 维度 | 传统 BI / 数据中台 | 本中台（决策操作系统） |
|---|---|---|
| 核心范式 | 数据 → 报表 → 人看 | 数据 → AI 归因 → 决策建议 → 一键行动 |
| 形态 | 看板罗列 | 5 张战略看板 + 智能 Push + 嵌入组件 |
| 用户视角 | 单产品 / 单业务 | 跨产品 / 跨业务的统一决策 |
| 价值闭环 | 数据展示 | 数据 + 决策 + 行动 + 复盘 |
| 组织能力 | 数据可见 | 决策方法论沉淀 |

## 战略目标（3 年）

- **第 1 年**：MVP 跑通，3 大产品线接入；总产品经理日常决策依赖中台
- **第 2 年**：全公司决策上中台；用户增长效率提升 ≥ 30%；ROI ≥ 5x
- **第 3 年**：决策方法论沉淀；AI 主动驱动 80% 异动响应；ROI ≥ 10x

## 关键非目标

为避免范围扩散，明确**不做**的事：

- ❌ 不做完整的数据治理平台（仅做与决策相关的指标治理）
- ❌ 不做大数据基础设施（复用现有数仓 / 第三方采集）
- ❌ 不做营销自动化系统（仅做 Journey 编排，触达通道复用现有）
- ❌ 不做完整的 CRM（仅提供画像组件给现有 CRM 嵌入）
