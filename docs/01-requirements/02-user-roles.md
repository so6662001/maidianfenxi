## 核心场景流程

### 场景 1：总产品经理早晨决策（决策入口）

```
08:00 收到企微推送 "今日决策摘要"
   ↓
08:05 打开 S-5 决策待办池
   ↓
看到 3 件紧急决策，选择 A 方案
   ↓
系统自动登记决策记录、派发任务、记录数据快照
   ↓
30 天后自动复盘提醒
```

### 场景 2：PM 诊断功能健康度

```
打开"功能健康度全景图"
   ↓
发现某功能落入"鸡肋"象限
   ↓
点击进入单功能详情页
   ↓
看到参数使用、零结果率、报错率等
   ↓
找到根因 → 提工单 / 启动 AB 实验
   ↓
登记决策到追溯库
```

### 场景 3：CSM 处理流失风险

```
打开"客户健康度榜"
   ↓
看到 ACME 健康分骤降
   ↓
点击进入 UserProfile360
   ↓
看到完整行为时间线、风险原因
   ↓
召唤决策助理"给我挽留方案"
   ↓
启动挽留 Journey + 自动派发任务
   ↓
14 天后自动复盘
```

### 场景 4：运营自助圈人触达

```
打开"分群构建器"
   ↓
拖拽配置"高潜流失"分群条件
   ↓
实时预估人数
   ↓
打开"Journey 编排器"
   ↓
设计 Day0/Day3/Day7 多通道触达
   ↓
配置 AB 实验
   ↓
启动 → 实时追踪效果
```

### 场景 5：业务系统嵌入用户画像

```
业务系统（如 CRM）页面
   ↓
通过 <UserProfile360 userId="xxx" /> 嵌入中台组件
   ↓
组件自动请求中台 API 拉取数据
   ↓
显示完整画像 + 一键操作按钮
   ↓
点击"加入分群" → 调用中台 API
```
