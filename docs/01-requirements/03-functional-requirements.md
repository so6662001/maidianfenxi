# 功能需求清单

## 一、功能模块全景

```
中台功能 (12 大模块)
├─ M01 身份与权限（OneID + RBAC + 租户）
├─ M02 数据采集（SDK + Collector + 埋点治理）
├─ M03 指标平台（指标定义 + 查询引擎 + 缓存）
├─ M04 标签平台（标签生产 + 标签消费）
├─ M05 分群引擎（自助圈人 + 实时分群 + 分群导出）
├─ M06 Journey 与触达（Journey 编排 + 触达通道 + 疲劳度控制）
├─ M07 AB 实验平台（实验配置 + SRM + 显著性 + 结果分析）
├─ M08 战略决策驾驶舱（5 张战略看板）
├─ M09 业务模型看板（3 套业务模型 + 1 增长决策中枢）
├─ M10 智能洞察引擎（异动 + 归因 + 建议 + 推送）
├─ M11 决策助理（对话式 BI + 6 级能力）
├─ M12 决策追溯库（决策登记 + 自动复盘 + 知识沉淀）
+ 嵌入式能力组件（独立 SDK 发布）
+ OpenAPI（对外开放）
```

## 二、模块详细功能

### M01 · 身份与权限

| 功能 | 优先级 | 说明 |
|---|---|---|
| OneID 用户身份打通 | P0 | 跨产品识别同一用户/企业 |
| SSO 单点登录 | P0 | 与现有 IAM 集成 |
| RBAC 角色权限 | P0 | 见 02-user-roles.md 权限矩阵 |
| 行级权限 | P0 | 按租户/产品线/组织过滤数据 |
| 字段级脱敏 | P1 | 敏感字段按角色脱敏 |
| 审计日志 | P0 | 所有重要操作全留痕 |
| 多租户隔离 | P0 | 严格隔离，不可跨租户 |

### M02 · 数据采集

| 功能 | 优先级 | 说明 |
|---|---|---|
| Java SDK（业务后端用） | P0 | analytics-java-sdk + Spring Boot Starter |
| Vue3 SDK（业务前端用） | P0 | @company/analytics-sdk |
| 数据采集服务（Collector） | P0 | 高吞吐网关，≥ 1万 QPS/Pod |
| 埋点元数据管理 | P0 | 事件/属性/字典统一注册 |
| 埋点覆盖率监控 | P1 | 数据 PM 看板 |
| 实时数据质量检测 | P1 | 字段完整率、异常事件、时间漂移 |

### M03 · 指标平台

| 功能 | 优先级 | 说明 |
|---|---|---|

| 指标审计 | P1 | 所有查询留痕 |
| 自然语言查询 | P2 | 与决策助理集成 |

### M04 · 标签平台

| 功能 | 优先级 | 说明 |

### M05 · 分群引擎

| 功能 | 优先级 | 说明 |
