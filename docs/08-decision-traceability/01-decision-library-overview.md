# 决策追溯库 · 概览

## 一、为什么是最被低估的资产

```
没有追溯库：决策 → 行动 → 结果（无记忆）→ 下次重蹈覆辙
有追溯库：  决策 → 行动 → 结果 → 复盘 → 知识沉淀 → 下次更准
```

**3-5 年后**，决策追溯库会是公司比"数据本身"更值钱的资产——沉淀的是"判断力"。

## 二、5 类决策与对应模板

| # | 类型 | 触发场景 | 模板特点 |
|---|---|---|---|
| 1 | **产品决策** | 砍/做/改功能 | 重点是用户影响、ROI |
| 2 | **资源决策** | 预算/人力分配 | 重点是 ROI、机会成本 |
| 3 | **战略决策** | 业务方向调整 | 重点是假设、长周期复盘 |
| 4 | **组织决策** | 团队调整、任命 | 重点是能力匹配、影响范围 |
| 5 | **应急决策** | 故障/危机响应 | 重点是快速登记、事后深复盘 |

详见 [5 种决策模板](./02-decision-templates.md)。

## 三、3 种触发方式

### 方式 1：业务模型看板直接触发

```
SaaS 看板 → NRR 异动 → 智能洞察归因
   ↓
助理建议："启动 P-SE-001 NRR 提升计划"
   ↓
用户点击 [记录决策]
   ↓
决策追溯库录入表单弹出，预填：
  · 决策类型：业务（NRR）
  · 关联模型：SaaS LCM
  · 关联指标：M-SE-001 NRR
  · 关联 Playbook：P-SE-001
  · 数据快照：当前看板 + 异动归因报告
  · 预期效果：NRR 提升 3pp（按 EXP-014）
  · 复盘节点：30/60/90 天
```

### 方式 2：Playbook 启动时强制登记

```
任何 ★★★★/★★★★★ Playbook 启动 → 自动创建决策记录
登记内容：
  · 决策类型：自动判定
  · Playbook 编号 + 实验编号
  · 触发数据：自动从指标平台抓取
  · 预期效果：从 Playbook 定义自动带入
  · 责任人：Playbook Owner
  · 复盘节点：与实验周期对齐
```

### 方式 3：战略评审会决策入库

```
人工触发 → 选择模板（5 种之一）→ 填写 → 提交
助理辅助：
  · 数据支撑自动检索三模型相关指标
  · 历史相似决策自动推荐参考
  · 预期效果智能推荐 KPI
```

## 四、数据快照机制（关键）

每个决策登记时自动冻结：

| 模型 | 快照内容 |
|---|---|
| SaaS LCM | LCM 漏斗 + NRR/GRR + 健康分布 + 续约风险地图 + Top10 风险客户 |
| AI 单位经济 | 单次毛利 + 价值采纳率 + 能力缺口矩阵 + Top 异常 Prompt |
| 平台双边流动性 | 供需热力地图 + 24h 响应率 + 撮合漏斗 + 失衡 Top10 类目 |

**存储方式**：
- 看板截图 PNG (永久存档)
- 原始数据 JSON (可重新渲染)
- 查询 SQL + 参数 (可复现)
- 存 OSS，跨区备份

## 五、关键功能

### 1. 决策创建入口（多入口）
- 战略看板"一键决策"按钮 → 预填模板
- 决策助理对话中"记录决策"命令
- 评审会议系统集成 → 会议结论自动落入

### 2. 数据快照机制
- 决策提交时自动冻结当前看板数据
- 永久存储到对象存储（含访问审计）

### 3. 自动复盘
- 到期前 3 天 Push 提醒
- 自动调取"决策时刻 vs 现在"指标对比
- AI 自动生成复盘初稿
- 责任人确认 + 补充经验沉淀

### 4. 知识沉淀与检索
- 经验标签库
- 全文检索 + 语义搜索（"砍产品的成功案例"）
- 新决策时助理自动检索历史相似决策
- 定期产出"季度决策方法论报告"

### 5. PM 效能榜数据源
- 每决策关联到决策人
- 自然形成"个人决策准确率"
- 反哺 S-3 排名

## 六、价值闭环

```
做决策 → 自动留痕 → 自动复盘 → 知识沉淀 → 下次决策时 AI 智能推荐相似案例
                                              ↑
                                         真正的"组织记忆"
```

## 七、与其他模块联动

- 决策追溯库 ↔ S-3 PM 效能榜（每决策关联到人）
- 决策追溯库 ↔ S-4 战略假设（战略决策关联假设）
- 决策追溯库 ↔ 智能洞察引擎（异动触发的决策自动登记）
- 决策追溯库 ↔ 决策助理（提建议时检索历史相似决策）

## 八、治理机制

| 项 | 规范 |
|---|---|
| 强制登记 | P0/P1 决策必须登记，未登记通知上级 |
| 复盘 SLA | 到期 3 天未做 → 上级通知；7 天未做 → 红色待办 |
| 复盘文化 | "对事不对人"，鼓励登记失败决策 |
| 隐私 | 涉敏决策（组织变动）权限严控 |
| 审计 | 决策修改全留痕，关键字段冻结后不可改 |
| 季度评审 | 总产品经理审视所有重大决策复盘质量 |
| 年度报告 | 产出"组织决策方法论白皮书" |
