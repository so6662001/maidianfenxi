# 跨产品分析 10 个具体场景

> 这是中台真正的"杀手锏"——单产品做不到，只有共用底座的中台能做。

## 场景速览

| # | 场景 | 价值 | 主要消费方 |
|---|---|---|---|
| 1 | 跨产品用户旅程地图 | 识别用户在多产品中的真实使用路径 | 总 PM、增长 |
| 2 | 多产品 LTV 对比 | 多产品客户是否真的更值钱？ | 总 PM、CFO |
| 3 | 跨产品交叉销售机会 | 最佳交叉销售时机和路径 | 销售、增长 |
| 4 | 跨产品用户画像 360° | 全域用户画像，运营更精准 | 运营、CSM |
| 5 | 跨产品流失先兆 | 单产品流失 ≠ 全域流失 | CSM、运营 |
| 6 | 跨产品付费转化阶梯 | AI 用户→SaaS 用户→平台用户 转化率 | 增长 |
| 7 | 跨产品组合定价分析 | 套餐捆绑设计依据 | 商业化 |

## 场景详细设计

### Q-01 · 跨产品用户旅程地图

| 字段 | 内容 |
|---|---|
| **业务问题** | SaaS 用户中有多少同时使用 AI？平台买家中有多少最终成为 SaaS 客户？ |
| **关键数据** | OneID 关联表 + 三产品行为事件 + 注册/付费时间戳 |
| **分析方法** | 桑基图：产品 A 注册 → 产品 B 触达 → 付费；按首次产品起源分群 |
| **可视化** | 多产品桑基（4 层）+ 转化率矩阵 |
| **关键指标** | 跨产品渗透率、跨产品付费率、跨产品平均时长 |
| **决策影响** | 决定哪些产品作为"入口产品"获客成本最低 / 哪些作为"价值产品"留存最强 |
| **示例洞察** | "SaaS 用户中 35% 试用 AI，付费转化 28%（vs 直接 AI 注册转化 8%）。AI 应作为 SaaS 扩展功能而非独立获客入口。" |

### Q-02 · 多产品 LTV 对比

| 字段 | 内容 |
|---|---|
| **业务问题** | 多产品客户的 LTV 是单产品的几倍？投入交叉销售值不值？ |
| **关键数据** | 用户/企业 ID + 各产品订阅/付费记录 + 历史 12-24 月 |
| **分析方法** | LTV 按"持有产品组合"分群对比：仅 SaaS / 仅 AI / 仅平台 / SaaS+AI / SaaS+平台 / 三全 |
| **可视化** | 横向条形图 + 留存对比折线 |
| **决策影响** | 决定交叉销售投入预算 |
| **示例洞察** | "三全产品客户 LTV 是单 SaaS 客户 3.2 倍，留存高 22pp。建议给 SaaS 客户每年 2 次 AI 试用钩子。" |

### Q-03 · 跨产品交叉销售机会

| 字段 | 内容 |
|---|---|
| **业务问题** | 推荐 SaaS 客户用 AI 的最佳时机？转化率最高的路径？ |
| **分析方法** | 1) 已交叉付费用户的"首次交叉付费前 7 天行为"反推关键钩子<br>2) 按时机分群（SaaS 第 30/90/180 天）AB 推 AI 触达<br>3) 按角色分群（Admin vs Member） |
| **关键指标** | 交叉转化率、转化时机、最佳触达通道 |
| **决策影响** | 自动化交叉销售 Journey 设计 |
| **示例** | "SaaS 客户第 60 天 + 用了'报表导出' + Admin 角色 = 交叉付费 AI 概率最高（28%）" |

### Q-04 · 跨产品用户画像 360°

| 字段 | 内容 |
|---|---|
| **业务问题** | 这个用户在我们所有产品中到底是什么样的？ |
| **关键数据** | OneID + 三产品行为 + 业务数据 + 触达历史 + 客服记录 |
| **形态** | `<UserProfile360>` 升级版，新增"产品矩阵"模块 |
| **关键展示** | 用户在每个产品的：注册时间、使用频次、付费状态、健康分、最近行为 |
| **决策影响** | 客服 / CSM / 销售上下文完整，避免"东问西问" |
| **示例** | 客服一眼看到：SaaS 重度、AI 中度、平台从未用，但近 7 天 AI 点踩 5 次 → 客服对应安抚 |

### Q-05 · 跨产品流失先兆

| 字段 | 内容 |
|---|---|
| **业务问题** | 用户在某产品流失之前，是否在其他产品也有信号？能否"全域早警"？ |
| **分析方法** | 1) 历史流失客户的"流失前 60 天跨产品行为"建模<br>2) 训练"全域流失先兆"分类器<br>3) 比对单产品 vs 全域模型预测准确率 |
| **关键指标** | 模型 AUC、提前预警时间 |
| **决策影响** | 客户健康分升级为"全域健康分"，CSM 提前介入 |
| **示例** | "SaaS 客户在 AI 出现 3 次点踩 + 平台流量包 ROI 跌破 1.5 = SaaS 续约失败概率 65%（vs 单 SaaS 信号 35%）" |

### Q-06 · 跨产品付费转化阶梯

| 字段 | 内容 |
|---|---|
| **业务问题** | 三产品的付费阶梯怎样？哪一步流失最严重？ |
| **分析方法** | 漏斗：免费 AI → 付费 AI → SaaS 试用 → SaaS 付费 → 平台会员 |
| **可视化** | 多层漏斗 + 各步流失原因 |
| **决策影响** | 设计完整的"入门 → 主力 → 高级"商业化路径 |
| **示例** | "免费 AI → 付费 AI 转化 8%；付费 AI → SaaS 试用 22%；SaaS 试用 → 付费 28%。三产品组合 LTV ¥120 万 / 客户。" |

### Q-07 · 跨产品组合定价分析

| 字段 | 内容 |
|---|---|
| **业务问题** | SaaS+AI 套餐应该定多少钱？折扣多少？ |
| **分析方法** | 1) 现有"组合付费"客户的实际付费意愿（WTP）<br>2) 价格弹性测试（AB）<br>3) 锚定效应分析<br>4) 与竞品/行业基准对比 |
| **关键指标** | 价格弹性、捆绑收益 vs 单买收益、满意度 |
| **决策影响** | 套餐设计、组合折扣、商业化策略 |

### Q-08 · 跨产品资源 ROI 对比

| 字段 | 内容 |
|---|---|
| **业务问题** | 我们的研发 / 销售 / CS 资源在三产品上的 ROI 对比？ |
| **关键数据** | 各产品研发人月 + 销售投入 + CS 投入 + 各产品收入与利润 |
| **分析方法** | 单位资源贡献（每人月贡献 ARR / 每销售支出贡献新签） |
| **可视化** | 散点 + 排名表 |
| **决策影响** | 资源在三产品的再分配，与 S-1 矩阵联动 |
| **示例** | "AI 团队人均产出 ARR 80 万（行业 200 万），建议外援高水平 LLM 人才或缩减规模" |

### Q-09 · 跨产品健康度联动诊断

| 字段 | 内容 |
|---|---|
| **业务问题** | AI 产品最近 NPS 下降，是否拖累 SaaS 续约率？ |
| **分析方法** | 1) 三产品健康分时序对比<br>2) Granger 因果检验<br>3) 客户级联动：使用多产品的客户在 X 产品下滑时是否影响 Y 产品 |
| **决策影响** | 不要只见树木不见森林，单产品下滑可能是全域问题 |
| **示例** | "AI 4 月点踩率上升后，相同客户在 SaaS 上的客服工单 +30%。AI 口碑问题正在污染整体品牌信任。" |

### Q-10 · 跨产品 NPS / 反馈聚合

| 字段 | 内容 |
|---|---|
| **业务问题** | 客户对"我们公司"整体满意度如何？ |
| **关键数据** | 三产品 NPS 调研 + 客服反馈 + 社交媒体口碑 |
| **分析方法** | 1) 同一客户在不同产品 NPS 对比<br>2) 文本反馈聚类（LLM）找跨产品共性问题<br>3) 公司级"品牌 NPS" |
| **可视化** | 客户级矩阵 + 反馈词云 + 趋势 |
| **决策影响** | 公司级品牌建设、跨产品体验一致性 |
| **示例** | "20% 客户在 SaaS 上给 NPS 9，但在 AI 上给 6 - 'AI 不够智能'是跨产品反复出现的关键词。" |

## 跨产品分析的基础设施要求

| 要求 | 说明 |
|---|---|
| OneID 准确率 | ≥ 95%，否则跨产品归因失真 |
| 数据时延一致 | 三产品数据同步刷新 |
| 指标口径统一 | "活跃用户"定义必须一致 |
| 权限矩阵 | 跨产品涉及多业务线，权限细粒度 |
| 计算性能 | 跨产品查询数据量大，必须宽表预聚合 |
