# SaaS Playbooks 详细库（15 个）

> 每个 Playbook 包含：触发 / 人群 / 内容 / 通道 / KPI / 实验设计。

## P-SA-001 · 高 CAC 渠道止血 ⭐⭐⭐⭐

| 项 | 内容 |
|---|---|
| 触发 | 单渠道 CAC 月环比 ↑ ≥ 20% 或 LTV/CAC < 1.5 持续 30 天 |
| 人群 | 渠道（非用户） |
| 动作 | 1) 立即冻结新增预算<br>2) 分析转化漏斗定位低转化环节<br>3) 转化率优化实验<br>4) 14 天未改善 → 暂停或减半 |
| 通道 | 内部企微通知 + 报表 |
| 主指标 | CAC 恢复、LTV/CAC 提升 |
| 责任人 | 增长负责人 |
| 实验 | EXP-009 |

## P-SA-002 · 渠道结构优化（季度） ⭐⭐⭐⭐⭐

| 项 | 内容 |
|---|---|
| 触发 | 季度评估 |
| 动作 | 1) 算所有渠道 LTV/CAC + 用户质量评分<br>2) Top 3 渠道扩投 30%<br>3) 末位 2 渠道暂停/减半<br>4) 中位渠道做实验 |
| 主指标 | 整体加权 LTV/CAC、新增 ARR 效率 |
| 实验 | EXP-010 |

## P-SAC-001 · Trial 智能引导 ⭐⭐⭐⭐⭐（P0）

| 项 | 内容 |
|---|---|
| 触发 | Trial 启动 |
| 人群 | 所有 Trial 用户 |
| 动作 | 14 天动态 Journey：<br>· Day 0：欢迎邮件 + 上手指南<br>· Day 3：未使用核心功能 → 1v1 沟通<br>· Day 7：个性化使用报告 + 成功案例<br>· Day 10：试用倒计时 + 限时折扣<br>· Day 12：决策人邮件 + ROI 测算<br>· Day 14：销售跟进 |
| 通道 | 邮件 + 站内 + CSM + 销售 |
| 主指标 | Trial→Paid 转化率 |
| 副指标 | Day 7 激活率、销售跟进效率、客单价 |
| 护栏 | 客服工单 (≤+10%)、退订率 (≤+0.5pp)、客户投诉 |
| 实验 | EXP-001 |

## P-SAC-002 · Onboarding 加速 ⭐⭐⭐⭐⭐（P0）

| 项 | 内容 |

| 实验 | EXP-002 |

## P-SE-004 · 降级阻击 ⭐⭐⭐⭐

| 项 | 内容 |
|---|---|
| 触发 | 客户主动提降级 |
| 动作 | 1) CSM 立即介入（< 2h）<br>2) 诊断根因（成本/使用率/竞品）<br>3) 针对方案：<br>　· 成本 → 分期/年付<br>　· 使用低 → 培训+激活<br>　· 竞品 → 高管+差异化<br>4) 实在无法挽回 → 优雅降级 |
| 主指标 | 降级阻击率、降级 ARR 损失 |
| 实验 | EXP-016 |
