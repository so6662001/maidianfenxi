# 实验设计文档（37 个）

## 实验设计统一模板

每个实验严格按 12 字段记录：

```
实验编号 / 名称 / 关联 Playbook
1. 业务背景 / 问题
2. 业务假设（H1）— 量化、可证伪
3. 主指标（Primary Metric）— 1 个
4. 副指标（Secondary）— ≤ 3 个
5. 护栏指标（Guardrail）— ≤ 3 个，恶化必须停
6. 实验设计：分流维度 / 分流比例 / 分组数
7. 样本量：基线、MDE、α=0.05、Power=80%
8. 预计时长：max(样本充足天数, 7 天周期完整性)
9. SRM 检查：开
10. 数据观测：每日仪表盘 + 3 天小复盘
11. 决策规则：达成/未达成/中性 三种情况
12. 风险与回滚条件
```

### 样本量公式

```
n = 2 × (z_α/2 + z_β)² × p(1-p) / d²
  α = 0.05 → z_α/2 = 1.96
  β = 0.20 → z_β = 0.84
  p = 基线率, d = 绝对提升量

速查表（每组 n 值，5% 显著、80% 功效）：
基线  +1pp    +2pp    +5pp
10%   13,000  3,500   700
20%   —       6,300   1,100
30%   —       —       1,300
50%   —       —       1,500
```

## 实验治理规范

| 项 | 规范 |
|---|---|
| 实验注册 | 必须事前注册，不允许"事后挑结果" |
| 实验复盘 | 结束 3 天内必须复盘，归档决策追溯库 |
| 并行实验 | 同一漏斗节点最多 3 个 |
| SRM | 所有实验强制开启 |
| 数据延迟 | T+1 即可，重要实验上 T+0 |
| 显著但效应小 | 提升 < 1% 即使显著也建议放弃 |
