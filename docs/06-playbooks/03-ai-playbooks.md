# AI Playbooks 详细库（12 个）

## P-AV-001 · 价值采纳提升 ⭐⭐⭐⭐⭐（P1）

| 项 | 内容 |
|---|---|
| 触发 | 价值采纳率周环比 ↓ ≥ 5pp 或 < 30% 持续 14 天 |
| 人群 | 全体活跃用户（可按场景分群） |
| 动作 | 1) 输出后默认显示"采纳/继续优化/重新生成"按钮<br>2) 高质量输出"复制"高亮引导<br>3) 输出末尾智能追问建议<br>4) Prompt 模板推荐<br>5) "成功用户案例"个性化推送 |
| 主指标 | 价值采纳率 |
| 副指标 | D7 留存、单会话毛利、TTFV |
| 护栏 | 点踩率 (≤+1pp)、Token (≤+10%) |
| 实验 | EXP-006，50/50 跑 14 天 |

## P-AV-002 · TTFV 加速（模板引导） ⭐⭐⭐⭐⭐（P1）

| 项 | 内容 |
|---|---|
| 触发 | TTFV > 5 min 或环比 ↑ ≥ 30% |
| 动作 | 1) 首屏 3 个示例任务卡片<br>2) Prompt 模板库前置（按职业/场景）<br>3) 首次成功输出立即引导采纳动作<br>4) 失败时给"为什么 + 建议"<br>5) Day 1 推送"成功用户案例" |
| 主指标 | TTFV、首次价值采纳率 |
| 副指标 | Day 7 复用率 |
| 实验 | EXP-019 |

## P-AU-001 · 模型路由优化 ⭐⭐⭐⭐⭐（P0）

| 项 | 内容 |
|---|---|
| 触发 | 单次会话成本 ↑ ≥ 15% 或单次毛利 < 阈值 |
| 动作 | 1) 训练意图分类器（小模型 + 规则）<br>2) 简单请求 → 小模型（GPT-4o-mini / Claude Haiku / Qwen-Turbo）<br>3) 复杂请求 → 大模型<br>4) AB 实验对比<br>5) 监控护栏指标 |
| 主指标 | 单次会话成本 ↓ ≥ 30% |
| 护栏（关键） | 价值采纳率 (不降 > 2pp)、点踩率 (不升 > 1pp)、用户满意度 |
| 分流 | 30/70（小流量优先） |
| 决策规则 | 成本 ↓ ∧ 护栏稳定 → 灰度扩 70/30 → 90/10 → 全量<br>护栏恶化即停 |
| 回滚 | 4h 自动监控 + 自动回滚 |
| 实验 | EXP-007 |

## P-AU-002 · 输出长度控制 ⭐⭐⭐⭐

| 项 | 内容 |
|---|---|
| 触发 | 单次会话 Token ↑ ≥ 20% |
| 动作 | 1) 系统 Prompt 加"简洁优先"<br>2) 默认精简版 + "展开详细"按钮<br>3) 用户偏好学习<br>4) Streaming 可主动停止 |
| 主指标 | Token 消耗 ↓ |
| 护栏 | 采纳率、满意度 |
| 实验 | EXP-020 |

## P-AR-001 · 习惯养成钩子 ⭐⭐⭐⭐（P1）

## P-AC-001 · 免费上限触达升级 ⭐⭐⭐⭐

| 项 | 内容 |
