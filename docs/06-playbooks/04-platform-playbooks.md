# 平台 Playbooks 详细库（10 个）

## P-L-001 · 商家响应激活 ⭐⭐⭐⭐⭐（P0）

| 项 | 内容 |
|---|---|
| 触发 | M-L-001 24h 响应率周环比 ↓ ≥ 5pp 或 单类目 ≤ 50% |
| 目标 | 24h 响应率 ≥ 70% |
| 人群 | 该类目下 24h 未响应询盘的商家 |
| 分群 | `seg_inactive_responder` |
| 动作 | 1) 站内信 + APP Push："您有 N 条新询盘"<br>2) 商家工作台首屏置顶<br>3) 24h 未响应 → 短信/电话<br>4) 48h 未响应 → 排序降权 24h<br>5) 高价值商家 V3+ → 客户经理 1v1 |
| 主指标 | 24h 响应率提升 |
| 副指标 | 商家续费率 |
| 护栏 | 投诉率（≤+3%） |
| 责任人 | 商家运营 |
| 实验 | 50/50 跑 14 天，投诉 > 3% 立即停 |

## P-B-001 · 类目失衡干预 ⭐⭐⭐⭐⭐

| 项 | 内容 |
|---|---|
| 触发 | 单类目供需比 > 5（供过于求）或 < 0.5（供不应求），持续 ≥ 14 天 |
| 双分支 | 见下方 |

**供过于求分支**：
1. 调整流量：该类目曝光位 +30%
2. 推荐位首页加该类目
3. 跨类目"相似商品推荐"导流
4. 短期补贴买家（运费/优惠券）
5. 商家工具：SEO 建议、爆款选品

**供不应求分支**：
1. 招商团队定向招商（PRD 输出"重点招商类目周报"）
2. 跨类目商家引导（"该类目需求旺盛"）
3. 智能推荐"相似替代类目"给买家
4. 买家"求购"功能让需求显性化

| 主指标 | 该类目供需比恢复 + 撮合成功率提升 |
|---|---|
| 实验 | EXP-031 / EXP-032 |
