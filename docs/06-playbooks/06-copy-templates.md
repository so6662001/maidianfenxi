# 触达文案库（37 Playbook 完整文案）

## 文案撰写原则

1. **每条文案 ≤ 6 秒能读完**（短信 70 字内，邮件标题 ≤ 20 字）
2. **以"用户视角"写**，避免"我们公司想..."
3. **每条带 1 个明确 CTA**
4. **个性化变量用 `{xxx}` 标注**
5. **多通道一致性，适配通道特性**

## 六、文案运营规范

| 项 | 规范 |
|---|---|
| A/B 文案 | 每个 Playbook 至少 2 版做实验 |
| 变量 fallback | {name} → "您"，{company} → "您的公司" |
| 发送窗口 | 工作日 9:00-21:00，避免午休 12-14 |
| 频次控制 | 单用户 24h 累计 ≤ 3 次 |
| 退订机制 | 邮件必备退订链接，企微/站内提供"减少推送" |
| 多语言 | 英文版同步准备（如有海外用户） |
| 审核 | 营销类文案需法务/合规审核 |
| 版本 | 每条文案有版本号 + 上线日期 |
