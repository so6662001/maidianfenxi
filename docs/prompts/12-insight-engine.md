# 提示词 12 · 智能洞察引擎

> 前置：`00-master-prompt.md`。参考：`docs/07-ai-assistant/03-intelligent-insight-engine.md`。

---

## 提示词正文

```
你是数据科学工程师。请开发 analytics-insight 服务。

【目标】
异动检测 + 智能归因 + 决策建议 + 推送 + 反馈学习 五层架构。

【技术】

- Spring Boot 3.2
- Python micro-service（Prophet / sklearn 算法，通过 gRPC 或 HTTP 调用）
- 或纯 Java：使用 smile-statistics 等
- LangChain4j（LLM 摘要 + 建议生成）
- Kafka（异动事件流）
- XXL-Job（调度）
- 复用 reach 服务做推送

【架构】

```
L4 学习层：反馈收集 → 调阈值 / 调推荐策略 / 调归因权重
L3 行动层：推送通道 + 决策待办池 + 一键行动按钮
L2 智能层：LLM 摘要 + 决策建议 + 自然语言报告
L1 分析层：异动检测 + 维度归因 + 因果分析
L0 数据层：指标平台 + 行为明细 + 业务上下文
```

【异动检测算法】

| 算法 | 适用 | 实现 |
|---|---|---|
| 阈值规则 | 业务明确告知 | Java 配置驱动 |
| STL 分解 + 3σ | 有季节性 | Python sklearn |
| Prophet | 复杂趋势 | Python facebook/prophet |
| Isolation Forest | 多维联合异常 | Python sklearn |

每个指标可配置敏感度（高/中/低）。

【调度】

```
实时指标：每 5 分钟扫描
离线指标：每日 06:30
战略假设进度：每周一 09:00
复盘到期：每日 09:00
早报：每日 08:00
周报：每周一 09:00
月报：每月 1 号 09:00
```

【归因算法】

1. 多维下钻 + Adtributor（Microsoft 论文）
2. 业务上下文关联：
   - 关联事件（变更日志 / 客诉 / 监控告警）
   - LLM 整合多源信号
3. 输出归因报告 + 贡献度排序

【决策建议生成】

```
触发条件                  → 候选建议库          → LLM 个性化包装
异动类型                  → 历史相似案例       → 结合上下文
影响范围                  → PM/CS Playbook 库  → 自然语言生成
紧急程度                  → 行业最佳实践       → 1/2/3 排序
历史相似事件              → 业务规则库         → 风险标注
```

每条建议：至少 3 个备选方案（A/B/C），带置信度。

【推送防过载】

- 单用户每天 ≤ 7 条
- 同问题 24h 去重
- 用户可关闭某类（带反馈）
- 重要度 < 阈值 → 摘要日报

【反馈学习】

```
推送 → 用户操作（处理/忽略/反馈"误报"/"不重要"）
   ↓
记录反馈库
   ↓
周度自动调优：
  · 被忽略指标 → 提高阈值
  · 被处理指标 → 降低阈值
  · 用户认可的归因维度 → 加权
  · AI 建议采纳率作为 Prompt 优化信号
```

【API】

```
GET  /api/insight/anomaly                # 异动列表（按时间 / 严重度）
GET  /api/insight/anomaly/{id}           # 异动详情 + 归因
POST /api/insight/anomaly/{id}/action    # 用户操作（处理/忽略/反馈）
GET  /api/insight/daily-digest           # 当日摘要
POST /api/insight/config/sensitivity     # 调整敏感度
```

【性能】

- 异动检测每次扫描 < 2 min
- 归因报告生成 < 30s
- 推送延迟 < 1 min

【评估指标】

- 异动检测召回率 ≥ 90%
- 异动检测误报率 ≤ 10%
- 归因准确率（人工抽检）≥ 80%
- 推送处理率 ≥ 70%
- 推送被标"误报/不重要"率 ≤ 15%
- AI 建议采纳率 ≥ 40%

【验证】

1. 异常注入测试（人为造异动验证检测准确率）
2. 归因准确性（对比历史已知事件）
3. 推送不雪崩
4. 反馈学习生效

【交付物】

- 完整服务代码
- 算法实现 / Python 微服务（如选）
- 归因报告模板
- LLM Prompt 模板
- 反馈学习配置
- 评估测试集

【安全】

- 敏感指标推送仅限授权人
- 异动详情含数据权限校验
- 归因不暴露敏感字段

现在请生成。
```
