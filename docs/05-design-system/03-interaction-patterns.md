# 交互模式与状态规范

## 一、交互通用原则

1. **每张看板回答 1 个明确业务问题**
2. **关键操作 ≤ 3 步**
3. **每个数据卡有"行动入口"**（点击下钻 / 一键操作）
4. **危险操作（删除 / 大规模触达 / 资金）必须二次确认**
5. **加载状态必须显示**（≥ 200ms 显示骨架）
6. **错误状态必须可重试**
7. **空状态必须有引导**

## 二、看板交互模式

### 时间筛选

- 默认快捷预设：今日 / 本周 / 本月 / 本季 / 本年 / 近 7 / 近 30 / 近 90 天
- 自定义：RangePicker
- 对比基准：环比 / 同比 / 自定义周期 / 无对比

### 下钻

- 单击聚合数字 → 明细列表
- 多级下钻支持面包屑回退
- 下钻状态保存在 URL（可分享）

### 联动

- 筛选器变化 → 全屏图表自动刷新
- 矩阵图 hover → 表格行高亮
- 表格行 hover → 图表点高亮

### 多选与对比

- Shift / Cmd 多选
- 选中 ≥ 2 项 → 浮出"对比"按钮
- 对比模式：并列表格 + 差异高亮

### 个性化

- 看板支持"保存视图"
- 多视图切换 Tab
- 默认视图 vs 个人偏好

## 三、状态规范（全部 4 种状态必须设计）

### 加载状态

```
触发：数据请求中
显示：Skeleton 骨架屏（避免转圈圈）
超时：3s 后追加"加载较慢，请稍候"提示
长时：> 30s 提示"后台计算中，结果将通过消息通知"
```

### 空数据状态

```
情况 1：首次进入无数据
  显示：引导图 + "请先配置..." + [前往配置] 按钮
  
情况 2：筛选无结果
  显示：Empty + "当前筛选无数据" + [清空筛选] 按钮

情况 3：未授权 / 无内容
  显示：友好文案 + 推荐相关功能
```

### 错误状态

```
情况 1：网络错误
  显示：Result + [重试] 按钮 + 错误码（DEV 环境）
  
情况 2：业务错误
  显示：Alert + 错误说明 + 解决建议

情况 3：服务降级
  显示：横幅 + 降级说明 + 联系方式
```

### 无权限状态

```
显示：
  Result 403 + 
  "您暂无权限查看此内容" + 
  [申请权限] 按钮 + 
  权限审批联系人
```

### 数据过期状态

```
触发：T+1 数据 > 36h 未更新
显示：顶部黄色 Banner："数据已过期，最后更新 XX 小时前 [刷新]"
```

## 四、表单交互

### 校验时机

- 失焦后校验（onBlur）
- 提交前全表单校验
- 实时校验仅对"明显错误"（如格式错误）

### 错误提示

- 行内提示：字段下方红字
- 整体提示：表单顶部 Alert（多错误聚合）
- 焦点：滚动到第一个错误字段

### 自动保存

- 长表单（≥ 10 字段）自动保存草稿（每 10s）
- 浏览器关闭前提示未保存

### 提交反馈

- 提交中：按钮 loading
- 成功：toast + 跳转或刷新
- 失败：保留输入 + 明确错误 + 重试

## 五、消息与通知

### 优先级

| 级别 | 通道 | 时机 |
|---|---|---|
| P0 紧急 | 站内 + 企微 + 短信 + 电话 | 立即 |
| P1 重要 | 站内 + 企微 | 工作时间 |
| P2 常规 | 站内 + 邮件日报 | 日报聚合 |
| P3 信息 | 站内 | 用户主动查看 |

### 防过载

- 单用户 24h 累计 ≤ 7 条
- 同问题 24h 去重
- 用户可关闭某类推送
- 高频推送进"摘要日报"

## 六、决策助理交互

### 唤起方式

| 方式 | 说明 |
|---|---|
| 右下浮窗 | 任意看板右下角 64×64 |
| 快捷键 | `Cmd/Ctrl + K` |
| 数据点击 | 卡片"💬 详谈"按钮 |
| 企微 Bot | 移动端 |
| 邮件回复 | 晨报内引导 |

### 对话规范

- 用户消息：右对齐 + 头像
- 助理消息：左对齐 + 助理头像
- 工具调用：可展开折叠
- 数据卡片：富文本渲染
- 操作按钮：每条回答下方

### 反馈

- 👍 / 👎 按钮
- 👎 弹出反馈框（"为什么不好？"）
- 反馈回流学习

## 七、键盘快捷键

| 快捷键 | 功能 |
|---|---|
| `Cmd/Ctrl + K` | 唤起助理 |
| `Cmd/Ctrl + /` | 帮助 |
| `Cmd/Ctrl + S` | 保存（适用场景） |
| `Esc` | 关闭弹层/抽屉 |
| `↑/↓` | 列表导航 |
| `Enter` | 确认 |

## 八、移动端

> 本中台**不专门做移动端 Web**。移动场景推荐：

- 企微/钉钉 Bot
- 决策助理小程序
- 移动端 H5 仅支持极简看板（订阅日报 / 决策待办池）

## 九、无障碍（A11y）

| 项 | 规范 |
|---|---|
| 键盘可达性 | 所有交互元素可 Tab |
| 焦点可见 | outline 明显 |
| ARIA 标签 | 复杂组件必备 |
| 色彩对比 | WCAG AA 标准 |
| 屏幕阅读器 | 关键操作支持 |

## 十、动效原则

- 微交互：≤ 150ms
- 弹层：250-400ms
- 页面切换：≤ 400ms
- 数据更新：500-800ms 平滑过渡
- 加载：避免突兀转圈，用骨架
- 减少动效（用户可设置）
