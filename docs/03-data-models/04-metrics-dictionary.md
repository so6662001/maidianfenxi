# 指标字典（60 个指标）

> 三模型完整指标清单，每个指标包含：业务定义、计算口径、维度、阈值、责任人、关联 Playbook。

## 命名规范

```
M-{域}-{编号}
  M : Metric
  域 : SA(SaaS-获客) SAC(SaaS-激活) SAD(SaaS-采纳) SE(SaaS-扩张)
       SR(SaaS-留存) SH(SaaS-健康) 
       AV(AI-价值) AU(AI-单位经济) AQ(AI-质量) AR(AI-留存) AC(AI-转化) AE(AI-效率)
       L(平台-流动性) B(平台-平衡) R(平台-留存) N(平台-网络效应) M(平台-商业化)
  编号 : 3 位数
```

## 一、SaaS LCM 指标（22 个）

### 获客类

#### M-SA-001 · CAC
- 定义：每个新付费客户的获取成本
- 口径：`(市场+销售) / 新增付费客户数`
- 维度：渠道、行业、规模、地区
- 阈值：PLG ≤ ¥2k / SLG ≤ ¥30k / 企业级 ≤ ¥200k
- 异动：月环比 ↑ ≥ 20%
- Playbook：P-SA-001 高 CAC 渠道止血
- 责任人：增长负责人

#### M-SA-002 · LTV/CAC
- 定义：客户终身价值 / 获取成本
- 口径：`LTV / CAC`
- 阈值：≥ 3 健康，≥ 5 优秀
- Playbook：P-SA-002 渠道结构优化

#### M-SA-003 · Payback Period
- 定义：收回 CAC 的月数
- 口径：`CAC / (月毛利 × 留存系数)`
- 阈值：≤ 12 月健康

### 激活类

#### M-SAC-001 · Trial→Paid 转化率 ⭐
- 定义：试用用户付费比例
- 口径：`paid_count / trial_count`
- 阈值：PLG ≥ 15% / SLG ≥ 25%
- 异动：周环比 ↓ ≥ 3pp

#### M-SAC-002 · TTV
- 定义：从注册到首次价值动作的时长
- 口径：`median(value_action_time - signup_time)`
- 阈值：≤ 24h 优秀 / ≤ 7d 健康

#### M-SAC-003 · 首日激活率
- 定义：首日完成关键激活的用户比例
- 阈值：≥ 50%

#### M-SAC-004 · Onboarding 完成率
- 定义：完成全部新手引导的比例
- 阈值：≥ 70%

### 采纳类

#### M-SAD-001 · 核心模块采纳率 ⭐
- 定义：已开通且活跃的企业比例
- 口径：`active_orgs / purchased_orgs`
- 阈值：≥ 60% 健康
- Playbook：P-SAD-001

#### M-SAD-002 · Seat 激活率
- 定义：已激活 Seat / 已购 Seat
- 阈值：≥ 80%

#### M-SAD-003 · Adoption Score
- 定义：综合采纳分（0-100）
- 口径：`核心模块×40% + Seat×30% + 高级功能×20% + API×10%`
- 阈值：≥ 70

#### M-SAD-004 · DAU/MAU 粘性
- 阈值：工具型 ≥ 30% / 工作流型 ≥ 50%

### 扩张续约类

#### M-SE-001 · NRR ⭐⭐
- 定义：净收入留存
- 口径：`(期初ARR + 扩张 - 收缩 - 流失) / 期初ARR`
- 阈值：≥ 110% 健康 / ≥ 130% 优秀
- Playbook：P-SE-001

#### M-SE-002 · GRR
- 口径：`(期初ARR - 收缩 - 流失) / 期初ARR`
- 阈值：≥ 90%

#### M-SE-003 · 续约率
- 口径：`renewed_logos / expired_logos`
- 阈值：中小客 ≥ 75% / 大客 ≥ 90%
- Playbook：P-SE-002

#### M-SE-004 · 扩张率
- 阈值：≥ 20% 健康
- Playbook：P-SE-003

#### M-SE-005 · 续约提前指数
- 定义：续约平均提前天数
- 阈值：≥ 30 天

### 留存类

#### M-SR-001 · Logo 留存率
- 定义：1 年前付费客户今天仍付费的比例
- 阈值：大客 ≥ 85% / 中小客 ≥ 70%

#### M-SR-002 · 流失原因分布
- 来源：访谈 + CRM 录入 + 行为推断

#### M-SR-003 · 流失预警准确率
- 定义：预测高风险中实际流失的比例
- 阈值：≥ 60% 健康

### 客户健康类

#### M-SH-001 · 客户健康分 ⭐
- 加权：30% 采纳 + 20% 活跃 + 15% Admin + 15% 续约 + 10% CSAT + 10% 商务
- 阈值：≥ 70 绿 / 50-70 黄 / < 50 红

#### M-SH-002 · NPS
- 阈值：≥ 30 健康 / ≥ 50 优秀

#### M-SH-003 · CSAT
- 阈值：≥ 4.5/5

## 二、AI 单位经济指标（20 个）

### 价值采纳类

#### M-AV-001 · 价值采纳率 ⭐⭐⭐
- 定义：会话产生采纳行为的比例
- 口径：`session_with_adoption / total_session`
- 采纳行为：复制 / 导出 / 继续追问 / 点赞 / 应用
- 阈值：≥ 40% 健康 / ≥ 60% 优秀
- 异动：周环比 ↓ ≥ 5pp
- Playbook：P-AV-001

#### M-AV-002 · TTFV ⭐⭐⭐
- 定义：注册到首次被采纳输出的时间
- 阈值：≤ 3 min 优秀 / ≤ 10 min 健康
- Playbook：P-AV-002

#### M-AV-003 · 高质量输出率
- 阈值：≥ 50% 健康

#### M-AV-004 · 单用户日均价值动作
- 阈值：工具型 ≥ 5

### 留存类

### 转化类

## 四、指标治理规范

| 项 | 规范 |
|---|---|
| 注册 | 必须在指标平台注册才可被查询 |
| 版本 | 计算口径变更需走评审 + 版本号 |
| 责任人 | 每个指标有 1 责任 PM + 1 数据负责人 |
| 审计 | 所有查询记录到 ES |
| 性能 | 慢查询超时自动 kill + 告警 |
| 缓存 | 按新鲜度配置 TTL |
| 物化视图 | 常用指标必须物化 |
| 评审 | 季度评审，下线无人使用的指标 |
