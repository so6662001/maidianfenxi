# AI 单位经济模型（Unit Economics for AI）

> 业务本质：**单位经济 + 价值采纳**。健康定义：价值采纳率 ≥ 40% + 单次毛利 > 0 + 7 日复用 ≥ 30%（**不是** DAU）。

## 一、核心方程

```
单次会话价值 (Value) = P(采纳) × 用户愿付价格
单次会话成本 (Cost) = Token输入×单价 + Token输出×单价 + 基础设施
单次会话毛利 = Value - Cost
产品健康 = 单次毛利 × 会话规模 × 留存
```

## 二、会话因果链

```
┌─────────┐
│  Prompt │ ←─── 模板库 / 引导降本
└────┬────┘
     │ Tokens(in)
┌────▼────┐
│  Model  │ ←─── 模型选型 / 路由降本
└────┬────┘
     │ Tokens(out)
┌────▼────┐
│ Response│
└────┬────┘
     │
┌────┴────┬──────┬──────┬──────┐
▼         ▼      ▼      ▼      ▼
复制/导出  追问   分享    点踩   放弃
(采纳)    (满意) (传播) (失败) (放弃)
     │     │      │     │      │
     └─────┴──────┴─────┴──────┘
                 │
        会话评分 → 反哺模型/Prompt 优化
```

## 三、价值采纳行为定义

| 行为 | 权重 | 信号强度 |
|---|---|---|
| 复制输出 | 高 | 最强：用户真实需要 |
| 导出内容 | 高 | 强 |
| 继续追问 | 中 | 中：表示有用但还需要 |
| 点赞 | 中 | 中（受文化影响） |
| 分享 | 高 | 强：愿意背书 |
| 应用到工作流 | 极高 | 极强：深度采纳 |

## 四、单位经济演进趋势

```
新产品上线：
单次毛利 < 0（亏钱获客）
   ↓
找到 PMF 后：
价值采纳率上升 → 用户愿付费率上升 → 单次毛利转正
   ↓
规模化：
模型路由 + 缓存 + 长度控制 → 成本下降 → 单次毛利提升
   ↓
持续优化：
质量优化 → 复用提升 → ARPU 提升 → LTV 提升
```

## 六、能力缺口分析方法

```
1. 离线对 prompt 做意图聚类（LLM Embedding + 聚类）
2. 计算每个意图簇的：
   - 会话数（规模）
   - 价值采纳率（满意度）
   - 点踩率（不满意度）
3. 绘制 2D 矩阵：意图 × 满意度
4. 识别"高频低满意"区域 = 能力缺口
5. 给每个缺口打优先级标签，进入路线图
```

## 七、模型路由策略

```
请求进入
   ↓
意图分类（小模型 + 规则）
   ├─ 简单（问候、改错、短问答） → 小模型（GPT-4o-mini / Claude Haiku / Qwen-Turbo）
   ├─ 中等（写作、总结、翻译） → 中型模型
   └─ 复杂（推理、分析、创作） → 大模型（GPT-4 / Claude Sonnet / Qwen-Max）
   ↓
执行 + 质量监控
   ↓
质量不达标 → 升级到更大模型重试
```
