# 平台双边流动性模型（Marketplace Liquidity）

> 业务本质：**双边市场 + 网络效应**。健康定义：24h 响应率 ≥ 70% + 撮合成功率 + 双边留存（**不是** DAU）。

## 一、双边市场全景

```
                       ┌─────────────────┐
                       │   网络效应飞轮   │
                       └────────┬────────┘
                                │
              ┌─────────────────┴─────────────────┐
              ▼                                   ▼
         供给侧 商家                            需求侧 买家
   ┌──────────────────┐                ┌──────────────────┐
   │ 入驻→上架→活跃   │                │ 访问→搜索→详情   │
   │  ↓ 库存质量      │                │  ↓ 留线索/询价   │
   │  ↓ 响应速度      │                │  ↓ 等待响应      │
   │  ↓ 报价质量      │                │  ↓ 比较/决策     │
   │  ↓ 成单率        │                │  ↓ 成交/反馈     │
   │  ↓ 续费/升级     │                │  ↓ 复购/推荐     │
   └────────┬─────────┘                └────────┬─────────┘
            │                                   │
            └──────────┬────────────────────────┘
                       ▼
                  ┌─────────┐
                  │ 撮合中枢 │ ←── 平台收 take rate / 会员费 / 流量费
                  └────┬────┘
                       │
              核心比率：
              · Liquidity (24h响应率) ≥ 70%
              · Match Rate (询盘→成单)
              · 供需比 (按类目)
              · Cross-side Retention
```

## 二、双边漏斗

### 买家漏斗

```
访问 → 搜索 → 详情页 → 留线索/询价 → 收到报价 → 决策 → 成交 → 复购
```

| 关键转化 | 健康阈值 | 干预 |
|---|---|---|
| 访问 → 搜索 | ≥ 60% | 优化首页推荐 |
| 搜索 → 详情 | ≥ 40% | 搜索结果排序、零结果补救 |
| 详情 → 留线索 | ≥ 15% | 详情页设计、信任元素 |
| 留线索 → 询价 | ≥ 40% | 询盘流程简化 |
| 询价 → 报价 | 24h ≥ 70% | **P-L-001 商家响应激活** |
| 报价 → 成交 | ≥ 15% | 撮合提升 |

### 商家漏斗

```
入驻 → 上架 → 活跃 → 收询盘 → 响应 → 报价 → 成单 → 续费/升级
```

| 关键转化 | 健康阈值 | 干预 |
|---|---|---|
| 入驻 → 上架 | 7 天 ≥ 80% | **P-AC-05 7 天上架冲刺** |
| 上架 → 活跃 | 月度 ≥ 70% | 推送热门类目 |
| 响应速度 | 24h ≥ 70% | P-L-001 |
| 报价中标 | ≥ 25% | 报价工具优化 |
| 续费率 | ≥ 75% | **P-R-002 商家续费保卫** |

## 三、网络效应监测

```
新增 100 个优质商家
   ↓
预期：买家活跃 +Δ buyers
   ↓
若 Δ > 0 且持续 → 飞轮转得动
若 Δ ≈ 0 → 飞轮停滞，需干预
若 Δ < 0 → 反飞轮（如商家质量差驱赶买家）
```

**计算方法**：线性回归月度数据，得弹性系数。

## 四、类目失衡管理

### 供需比阈值

| 供需比 | 状态 | 干预 |
|---|---|---|
| > 8 | 严重供过于求 | P-B-001：流量倾斜、补贴买家、商家工具 |
| 5 - 8 | 供过于求 | 同上但轻量 |
| 0.5 - 5 | 健康 | — |
| 0.3 - 0.5 | 供不应求 | P-B-001：招商团队介入 + 跨类目激活 |
| < 0.3 | 严重供不应求 | P-B-001 紧急 + 跨类目替代推荐 |

### 类目失衡干预决策树

```
检测到失衡（持续 14 天）
   ↓
判断方向（供过/供不）
   ↓
   ├─ 供过 → 增加流量 + 优惠买家 + 跨类目导流
   └─ 供不 → 招商 + 买家"求购"功能 + 替代品推荐
   ↓
30 天后评估恢复情况
   ↓
未恢复 → 升级到平台运营总监
```

## 五、流动性体验保障（平台命脉）

```
买家询盘 6h 无响应
   ↓
平台运营客服介入（电话/企微催商家）
   ↓
同时给买家推备选商家（避免空等）
   ↓
12h 无响应
   ↓
平台代替商家给买家致歉 + 优惠券 + 加急
   ↓
24h 无响应
   ↓
平台运营总监介入 + 该商家排序降权 24h
```

这是 **P-L-001 + P-R-005 联动 Playbook**，是平台业务的命脉保障。

## 六、反作弊与风控

| 异常 | 检测 | 处置 |
|---|---|---|
| 商家刷询盘 | 同 IP / 设备 / 时间集中 | 风控冻结 + 调查 |
| 买家恶意询价 | 频繁询价不成交 | 信用分降级 + 限流 |
| 虚假报价 | 报价后无后续 | 商家信用分降 |
| 库存质量差 | 图片不清 / 描述少 | 自动降权 + 整改通知 |

## 七、商业化层

### 收费模式
- **会员费**（商家分等级 V1/V2/V3）：固定年费 + 功能权益分级
- **流量费**：商家购买"流量包"，按曝光/点击/线索计费

### 关键指标
- **GMV**：撮合成交总额
- **Take Rate**：平台收入 / GMV（≥ 3%）
- **会员 ARPU**：人均会员费收入
- **流量包 ARPU**：人均流量费收入
- **流量包 ROI（商家视角）** ≥ 3x，否则不可持续卖
